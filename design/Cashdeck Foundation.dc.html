Accent Cashdeck Cobalt oklch(0.52 0.16 262) sits 18° cooler, 0.06 darker and calmer than Lifedeck indigo oklch(0.58 0.2 280), same family, own identity. Money semantics are derived by one rule per theme (light fg L 0.50, container L 0.945; dark fg L 0.80, container L 0.30) so hue is the only variable, and every status also carries an icon and a label. Expense is rose (355°), failed is red (27°), overdue is orange (50°), never confused, never colour-only.
