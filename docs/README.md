## Design history

The screens were designed from written briefs before they were built. These
files are kept as a record; the code and [apps/mobile/docs/design.md](../apps/mobile/docs/design.md)
are the current source of truth.

- [design-brief.md](design-brief.md): the first brief (foundation and screens)
- [design-review.md](design-review.md): the review of the first delivery
- [design-brief-insights.md](design-brief-insights.md): the insights redesign
- `design/`: the delivered prototypes, as HTML
